A brutally honest but still polite out-of-office auto-reply, written by a small Python program for make.fun's "The Painfully Honest Out-of-Office" bounty. It admits the sender is relieved to be away, promises the inbox will be read in order of how little it ruins the holiday, and thanks the reader — honest enough to quote, polite enough to survive being forwarded to a manager.

## Run it

```sh
python3 main.py
```

Writes one 163-character sentence to `/output/entry.txt`.
